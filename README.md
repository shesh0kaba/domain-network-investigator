# Domain Network Investigator

Повторяемый поиск новых неймингов, рекламных страниц и сайтов под брендовый поиск. Один скил для **Codex, Claude Code и Claude с загрузкой пользовательских skills**. Инструкции агента — на английском; общаться и составлять отчёты он должен на языке пользователя.

Входная точка — SEO-сайт, рекламная ссылка, лендинг или страница под новость. Скил ведёт исследование через имена, прямые IP, DNS/NS, код, формы, словари названий, повторяющийся контент и рекламные связи. Найденные сайты становятся следующими точками поиска.

Главный результат — **новые наблюдаемые нейминги и их SEO-сайты**, включая названия, для которых сайт ещё не найден. Профили команд, доказательства и история словарей хранятся отдельно. Репозиторий содержит методику и инструменты; исходные расследования и их базы в него не включены.

## Быстрый старт

Скачайте репозиторий или клонируйте его:

```sh
git clone https://github.com/shesh0kaba/domain-network-investigator.git
cd domain-network-investigator
```

Нужны Python 3.10+ для локальных помощников и доступ агента к веб-поиску/публичным страницам. Python-пакеты и API-ключи не требуются. Скил не предоставляет платную базу reverse-IP, рекламные аккаунты или гарантированно полный список доменов. При отсутствии части инструментов агент фиксирует ограничение и использует доступные источники.

### Codex

Из корня скачанного репозитория:

```sh
python scripts/install_skill.py --client codex
```

Установка: `~/.agents/skills/domain-network-investigator/`. Для одного проекта:

```sh
python scripts/install_skill.py --client codex --project /path/to/research-project
```

В Windows вместо `/path/to/research-project` укажите свой путь в кавычках. Если `python` отсутствует в PATH, используйте доступную команду Python 3.10+, например `py -3`.

Начните новую сессию в рабочей папке исследования и вызовите:

```text
Используй $domain-network-investigator. Новая команда «Название».
Начальная ссылка: <URL>. Это рекламная страница / сайт под поиск.
Ищи новые нейминги, их SEO-сайты и точные рекламные ссылки.
Веди общую таблицу и сохраняй состояние для повторных проходов.
```

Пути установки соответствуют [документации Codex](https://learn.chatgpt.com/docs/build-skills). Для клиента с другим настроенным каталогом можно передать `--dest /path/to/skills/domain-network-investigator`. Не создавайте несколько активных копий одного скила.

### Claude Code

```sh
python scripts/install_skill.py --client claude
```

Установка: `~/.claude/skills/domain-network-investigator/`. Для проекта добавьте `--project /path/to/research-project`; скил попадёт в `.claude/skills/`. В новой сессии:

```text
/domain-network-investigator Новая команда «Название». Начальная ссылка: <URL>.
Ищи новые нейминги, SEO-сайты и рекламные страницы. Сохраняй историю.
```

Это стандартные каталоги и вызов из [документации Claude Code](https://code.claude.com/docs/en/skills).

### Claude: загрузка ZIP

Скачайте [domain-network-investigator.zip из последнего релиза](https://github.com/shesh0kaba/domain-network-investigator/releases/latest/download/domain-network-investigator.zip). В Claude откройте **Customize → Skills → + → Create skill → Upload a skill**, загрузите ZIP и включите скил. Доступность зависит от настроек аккаунта, включая выполнение кода. См. [инструкцию Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude).

Архив содержит папку `domain-network-investigator/` с `SKILL.md` и всеми ресурсами. Обычный GitHub **Download ZIP** содержит весь репозиторий и для этого способа установки не предназначен. Формат пакета описан в [документации создания skills](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills).

В чате напишите: «Используй domain-network-investigator, новая команда …». Между сессиями передавайте сохранённый `investigation-state/` и связанные материалы: наличие скила само по себе не переносит результаты прошлого исследования.

### Обновление

Установщик отказывается заменять существующую папку. Сначала сохраните свои изменения, затем осознанно замените установленную копию новой версией. Состояние исследований хранится отдельно от скила и не должно удаляться при обновлении.

## Инструкция для нейронок

Точки входа: [AGENTS.md](AGENTS.md) для агента, [CLAUDE.md](CLAUDE.md) для Claude Code, [полный порядок работы](skills/domain-network-investigator/references/agent-guide.md) внутри переносимого скила.

Можно передать агенту такую инструкцию, даже без автоматической установки:

```text
Прочитай AGENTS.md в репозитории shesh0kaba/domain-network-investigator,
затем skills/domain-network-investigator/SKILL.md и references/agent-guide.md
внутри этой папки скила. Применяй методику к моей следующей задаче.
Используй доступные инструменты своей среды. Не выдумывай результаты
недоступных проверок. Храни состояние и отчёты в моей рабочей папке,
не загружай материалы исследования в публичный репозиторий.
```

Если агент не может открыть GitHub, передайте ему скачанную папку или ZIP скила. Одного README недостаточно для выполнения методики.

Повторный проход:

```text
Продолжай по команде «Название», состояние находится в <путь>.
Начни с свежих доменов и незавершённых зацепок. Ищи новые нейминги,
SEO-сайты, точные рекламные страницы и обновлённые словари.
Свежие домены на прямых IP сохраняй даже без работающего сайта.
Добавляй находки в общую таблицу, сортируй по новым регистрациям.
```

## Что сохраняется между проходами

- Реестр доменов, точных URL, неймингов и алиасов с источниками.
- Отдельный профиль каждой команды, её признаки и контрпримеры.
- Снимки словарей, новые/исчезнувшие/повторно появившиеся имена.
- Очередь дальнейших проверок и журнал фактически выполненных запросов.
- Общая таблица: **нейминг → SEO-сайт → точная рекламная/исходная страница → дата регистрации каждого домена → связь и статус**.

Новые домены сортируются первыми, неизвестные даты — последними. Дата регистрации домена не считается доказанной датой создания нейминга. По запросу пользователя она может отображаться как явно помеченная оценка для нового элемента словаря.

Совпадение IP через CDN/прокси не создаёт кандидата команды. Прямой IP служит сильной зацепкой для поиска; общая инфраструктура и код сами по себе не доказывают общего владельца. Страница с SEO-структурой и подтверждённый результат Google — разные статусы.

## Инструменты и проверки

| Файл | Назначение |
|---|---|
| `scripts/install_skill.py` | Копирование скила в выбранный клиент, без перезаписи |
| `scripts/package_skill.py` | ZIP скила и контрольная сумма для релиза |
| `skills/domain-network-investigator/scripts/init_state.py` | Новый пустой реестр одной команды |
| `…/scripts/state_tool.py` | Проверка состояния и новизны кандидатов |
| `…/scripts/collect_public.py` | Ограниченный сбор публичных страниц, кода, DNS/RDAP |
| `…/scripts/compare_evidence.py` | Сопоставление сохранённого кода и форм |
| `…/scripts/dictionary_diff.py` | Разница версий словаря в пределах команды |

Помощники не являются автономным поисковиком: выбор зацепок, поиск, извлечение имён, проверка связей и обновление таблицы выполняет агент. Коллектор читает HTML/код, не запускает JavaScript и не отправляет формы. Неполная индексация, JS-рендеринг, локализация и недоступность источников ограничивают результат.

Локальные проверки без сети:

```sh
python -m unittest discover -s tests -v
python scripts/package_skill.py --out dist
```

Проверяются изоляция профилей, история словарей, защита снимков от перезаписи, пути и формат пакета. Это не end-to-end проверка поиска в Claude и Codex. Проверку поведения агента проводите по [сценариям](docs/acceptance-scenarios.md) в своей среде.
